# 📈 Trade Journal

A personal, dark-themed trading journal application designed to log, track, and analyze trading performance. 

## 🎯 About The Project

This project is a private web application built to help maintain trading discipline. It provides a structured way to record daily trades, visualize performance over time, and learn from past mistakes using data and AI.

### ✨ Key Features

- **Private Dashboard:** Secure user authentication to keep all trading data and journals private[cite: 7].
- **Comprehensive Trade Logging:** Record detailed trade information including Entry, Stop Loss, Take Profit, Lot size, Timeframe, and Session[cite: 8].
- **Visual Proof:** Upload and compare "Before" and "After" chart screenshots for every trade[cite: 8].
- **Performance Analytics:** Auto-calculated metrics such as Win Rate, Profit Factor, Cumulative P/L, and Equity Curve[cite: 6, 9].
- **Discipline Tracker:** Compare the win rate and profitability of "Followed Plan" vs. "Deviated from Plan" trades[cite: 6, 9].
- **AI Trading Coach:** Integrated with Google Gemini AI to analyze trade history, summarize portfolio health, and provide actionable feedback based on personal stats[cite: 5, 6, 8, 10].

### 🛠️ Built With

- **Frontend:** React (Vite), React Router[cite: 1, 2]
- **Backend & Database:** Supabase (Auth, PostgreSQL, Storage)[cite: 4, 7, 8]
- **Charts:** Recharts[cite: 6]
- **AI:** Google Gemini API[cite: 10]
